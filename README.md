# Language Translation Tool 

This repository contains the source code for the **Language Translation Tool**, developed as **Task 1** for the **CodeAlpha** Internship program.

Features
- Multi-Language Translation: Translate text smoothly between various languages.
- Text-to-Speech: Listen to both the input and translated text using the speech button.
- Copy to Clipboard: Easily copy the translated text with a single click.
- User-Friendly Interface: Clean, responsive, and intuitive UI design.

Technologies Used
- HTML5: For structuring the web page.
- CSS3: For styling and responsive design.
- JavaScript: For core logic, API fetching, and DOM manipulation.

Files Structure
- `index.html` - The main HTML document.
- `style.css` - The stylesheet containing UI designs.
- `script.js` - The logic for translation, speech, and copy functionalities.

How to Run the Project
1. Clone this repository or download the ZIP file.
2. Extract the files to your local machine.
3. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, etc.).
4. Start translating!
